# Demonstration videos

Start with `01`, then watch the demos in any order.

| File | What it shows |
|---|---|
| `01-Volition-explanation.mp4` | Full walkthrough of the project (about 5 min) |
| `02-Intent-demonstration.mp4` | Biosignal gestures triggering actions |
| `03-Error-detection.mp4` | Signal-health detection (loose electrode, no signal) |
| `04-Virtual-HID-keyboard.mp4` | Gyro-controlled on-screen keyboard |
| `05-Device-control.mp4` | IMU-assisted control of a smart device |

All five videos are under 10 MB so GitHub can play them: click a file name, then press play. If a video still will not play in your browser, click **Download raw file** (top right of the file page) and open it on your computer.
